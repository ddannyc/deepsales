# 人工 AI 回复建议（T17）

当前人工负责人可选择具有当前渠道权限的已发布 AI，使用其冻结发布配置和工作区知识生成建议。
上下文仅来自当前会话：最新客户文字输入、最多 48 条既有客户输入及已发送回复，总输入预算 8,000 code points。
生成不会改变分配、HUMAN_ONLY 或创建客户可见消息，也不会调用转人工、工具或媒体发送。
知识引用通过现有 grounding 验证；不能形成安全文字建议时显示失败并保留人工草稿。

`reply_suggestion` 保存输入锚点、上下文消息 ID、配置快照/版本、原始建议、知识引用和发送消息 ID。
人工可编辑、取消或明确确认发送，普通草稿保持原状。
新客户输入使旧建议失效；提交结果及发送均在 PostgreSQL 会话锁内检查新鲜度和当前人工负责人。
发送使用建议 ID 作幂等键，已合法提交的消息按既有出站流程独立送达。
取消仅取消预览，不撤销已经开始的提供方调用；晚到结果不会恢复已取消预览。

用量类型 `SUGGESTION`，检索和生成合计一次逻辑操作，提供方尝试分别记录。
安全失败遵循既有有限重试与退避，未知结果暂停，同一请求复用用量及提供方响应。
额度不足、权限收回、客户新输入和发送失败不自动外发。
迁移 `0037_reply_suggestions.sql` 新增建议表并扩展用量类型，无存量数据删除。
生产需按现有备份与独立迁移流程操作；替身验证不代表真实模型的建议质量。
