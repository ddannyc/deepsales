# 多轮测试台（T20）

管理员可使用已保存草稿、当前发布版本或指定历史版本开始隔离测试。
开始时冻结配置快照及版本；后续编辑或发布不替换正在测试的快照。
模拟属性与标签引用当前工作区定义，沿用真实类型、选项、长度和引用校验。
来源、语言及手工记忆只作为测试数据，不作为公司知识依据或指令。
模拟语言使用现有语言代码校验（如 en、zh-CN）；自动语言沿用测试内已确定语言，固定模式保持配置语言。

`ai_test_session` 保存创建者、冻结配置、模拟资料、上下文代次和有序测试操作 ID。
每轮复用现有 `TEST` 用量预约、provider 尝试和诊断；同一请求不重复逻辑计费。
同一测试串行生成；未知结果暂停，新问题不能绕过尚未完成的运行。
每次清空原子取消未完成操作、递增代次、清空上下文及模拟资料，晚到结果不能写回。
已发生的 provider 调用仍保留用量记录，不能承诺撤回调用或退款。
浏览器仅在 sessionStorage 保存会话 ID，刷新后经授权 API 恢复；不保存客户内容到本地存储。

每个上下文最多 50 轮；提供给模型的历史最多 48 条消息，与当前输入合计 8,000 Unicode code points。
仅已完成轮次参与历史；失败、取消和未知结果保留诊断但不能冒充有效回答。
测试不创建 Customer、Conversation、Assignment 或 Message；转人工和素材只模拟，不执行真实写动作。
工作区权限及模拟定义在结果提交前重新检查；生产客户和线上分配不受测试影响。

迁移 `0038_ai_test_sessions.sql` 只新增隔离测试表、索引和约束，无存量数据删除。
生产按已有备份和独立迁移流程执行；批量测试和人设引导由 T22/T21 后续交付，真实模型质量仍需另行验收。
