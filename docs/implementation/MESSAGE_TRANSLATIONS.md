# 会话及发送翻译（T16）

客户及人工文字消息保留原文，译文通过独立开关、目标语言和预览操作查看。
人工回复开启发送前翻译后，Enter 不发送原稿；必须预览并明确确认发送译文。
支持英语、中文、西班牙语、法语、德语、日语、葡萄牙语和阿拉伯语。

`message_translation` 分别保存原文、输入版本、目标语言、译文及发送消息 ID。
发送确认必须匹配持久化结果，使用翻译 ID 作为发送幂等键；修改原稿或语言使旧预览失效。
切换会话后旧请求不得更新当前草稿。历史消息译文按请求成员、消息和目标语言复用。
草稿翻译及完成结果要求当前人工负责且具有渠道权限；消息翻译遵循收件箱查看权限。

翻译使用现有模型适配器和工作区逻辑操作额度，类型为 `TRANSLATION`。
同一操作重试复用提供方响应及计费记录；可判断失败遵循现有有限重试与退避。
发送结果或提供方结果不明时暂停，额度不足、失败或权限变化均保留原稿，不自动发送。
原稿上限 2,000 字符；历史消息翻译上限 8,000 字符，返回译文上限分别为 2,000 和 12,000。

迁移 `0036_message_translations.sql` 新增翻译记录并扩展用量类型，无存量数据删除。
生产部署前需按现有操作流程备份并单独应用迁移。
验证覆盖真实 PostgreSQL、Worker 路由及提供方替身、浏览器原文/译文和确认发送流程。
替身测试验证系统行为，不证明真实模型的翻译质量。T17 回复建议单独实现。
